# Optional Intent specialist

Read [the delivery contract](../hype-coordinate/references/team-contract.md). Enter
only when an approved Epic conflicts with existing Intent, a product decision is
actually missing, or Jay asks to turn a brainstorm into execution input.

Preserve confirmed decisions, hypotheses, open decisions, non-goals, and the first
observable acceptance result. Reuse existing requirements and issues. Add only the
criteria needed for the next user-visible slice; do not require a complete document
tree before implementation starts.

Return the resolved Epic or one focused Korean question for a decision that cannot
be inferred. Hand the result directly to the Delivery Captain. Do not discover the
global backlog, assign workers, create packet/session ACK state, poll GitHub, or
become a second coordinator.
