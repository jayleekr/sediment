## 1. 6-week sales motion

```
Week -1 (5/19~5/25): 사전 준비
Week 0  (5/26):      맛빼기 세션 (이미 잡힘)
Week 1  (5/27~6/2):  Free trial 시작 + 첫 음성 메모
Week 2  (6/3~6/9):   첫 회의 녹음 + 결정 추출 검토
Week 3  (6/10~6/16): 종이 회의록 batch upload + 위생사 데모
Week 4  (6/17~6/23): "신입 시뮬레이션" — RAG chat 시연
Week 5  (6/24~6/30): 가격 협상 + 계약 ($90/mo or ₩900K/yr)
```

### Week 0 — 5/26 맛빼기 세션 (당일)

**Sediment는 이 세션에 등장하지 않음.** 4원칙 체험에 집중. 단:
- 세션 말미 5분에 "이런 운영 노하우들이 매일 어디로 사라지는지 궁금하셨죠?" 한 마디만 미리 깔기
- 명함/카톡 교환만 받음 — 영업은 다음 주

### Week 1 (5/27~6/2) — Free trial 시작 + 첫 음성 메모

**Day 1 (월) 첫 미팅 (30분, 줌 또는 방문)**
- 원장님께 직접 시연:
  1. `sediment.hypeproof-ai.xyz` 접속 → GitHub OAuth 로그인
  2. 새 tenant 자동 생성 ("보아치과")
  3. 🎤 음성 메모 버튼 → 원장님이 5분 dump: "요즘 환자 늘어서 데스크 1명 더 뽑을지 고민 중인데..."
  4. 5분 후 결과 화면 → "결정: 데스크 추가 채용 검토 / 액션: 인사담당과 논의"
- **환자 데이터는 절대 안 만진다고 명시적으로 보여줌**: "원장님 카톡은 안 봅니다. 음성/회의록/메모만요."
- 다음 단계: "이번 주 동안 음성 메모 5-10개만 해보세요. 다음주 결과 같이 봐요."

**Day 4-7**: 원장님이 자발적으로 음성 메모 사용 (white-glove 기간)
- 우리가 모니터링: `fly logs -a hypeproof-sediment | grep boah` 로 사용량 추적
- 막힐 때 카톡으로 "음성 메모 잘 되시죠?" 가벼운 체크인 1회

### Week 2 (6/3~6/9) — 첫 회의 녹음 + 결과 검토

**Day 8 (월) 두 번째 미팅 (1시간)**
- 음성 메모 7-10개에서 추출된 결정/액션 같이 검토
- 원장 반응: "어... 진짜 다 잡았네... 이걸 위생사한테도 보여줄 수 있다고?"
- **회의 녹음 셋업**: 다음 월례 회의(보통 매월 첫 월요일) 녹음 시연
  - Consent screen 보여줌 — "참석자 동의 안 받으면 시작 못 합니다. 법적 부합 위해서요."
  - 위생사/코디에게 사전 카톡 보냄: "다음 회의 녹음됩니다, 회의 시작 전 클릭 동의 부탁"

**Day 9-14**: 첫 월례 회의 녹음 (보통 화/목)
- 1시간 회의 → Whisper 자동 전사 → diarized transcript
- 결정 3-5개, 액션 5-10개 추출
- Library에 artifact 1개 자동 생성

### Week 3 (6/10~6/16) — 종이 회의록 batch + 위생사 데모

**Day 15 (월) 세 번째 미팅 (1시간)**
- 회의 녹음 결과 같이 검토
- "이전 12개월 종이 회의록도 한 번에 올려보실래요?" → 30장 사진 batch upload
- Claude vision OCR → 12개월치 운영 결정 archive 자동 생성
- **이 시점에 원장 본인의 사용 만족도 거의 확정 (Week 3 retention)**

**Day 16 (화)** — 위생사 1:1 데모 (30분)
- 위생사가 직접 RAG chat 사용:
  - "환자가 '시술 다음 날 부었다'고 카톡 왔는데 어떻게 응대해요?" 
  - → AI: "원장님이 3월 회의에서 결정한 일반 가이드 — [출처: 2026-03 회의록] 1) 24시간 안에 ... 2) 부기 심하면 즉시 ..."
  - 위생사: "어... 이거 진짜 도움 된다"
- ⚠️ **환자 응대 시뮬레이션은 일반화된 SOP만** (개별 환자 X)

### Week 4 (6/17~6/23) — "신입 시뮬레이션"

**Day 22 (월) 네 번째 미팅 (1시간)**
- "다음 주 신입 위생사 들어옵니다" 가정
- 신입에게 30분만에 다음 알게 해야 함:
  1. 시술 가격 정책
  2. 환자 응대 SOP (일반)
  3. 비품 발주 절차
  4. 휴가 신청 방법
  5. 원장 부재 시 비상 대응
- RAG chat 시뮬레이션 → 5개 다 1-2분 안에 evidence-grounded 답변 + 인용
- **원장 결정의 순간**: "이거 없이 어떻게 살았지..."

### Week 5 (6/24~6/30) — 가격 + 계약

**Day 29 (월) 마지막 미팅 (45분) — 클로징**
- ROI 계산 같이:
  - 위생사 인수인계 시간: 평균 2주 → 3일로 단축 = ₩100만 × 4명/년 = ₩400만 절감
  - 원장 부재 시 의사결정 마비 0회 (이전: 월 2-3회)
  - 컴플라이언스 자료 (PIPA 부합 audit log) 자동 생성
- 가격 제시: **₩99,000/mo or ₩990,000/yr (1달 무료)**
- **계약 또는 1개월 연장 trial 결정**
- 원장님 표정 + "한 번 같이 해봅시다" 확약 → 성공

## 2. Sediment 안 만지는 것 (영업 도구)

이걸 명시적으로 보여주는 게 차별점:

| 항목 | 우리가 안 만짐 | 이유 |
|---|---|---|
| 환자와의 카톡 1:1 | ❌ 절대 | PIPA + 의료법 26조 |
| 환자 진료차트 | ❌ 절대 | 의료법 + 별도 진료 시스템 영역 |
| 환자 응대 SMS / 카톡 알림톡 | ❌ 절대 | 환자 동의 없음 |
| 직원 개인 카톡 (사적 대화) | ❌ 절대 | 근로자 사생활 보호 |
| 거래처 카톡 단톡방 | ❌ 거래처 동의 없으면 X | PIPA 위반 |

| 항목 | 우리가 만짐 | 동의 흐름 |
|---|---|---|
| 원장 본인 음성 메모 | ✅ | BYOData (원장 본인) |
| 직원 회의 녹음 | ✅ | 회의 시작 전 명시적 동의 (consent screen) |
| 종이 회의록 / 화이트보드 사진 | ✅ | 회사 자료, 외부 PII 없음 |
| (옵션) KakaoWork 워크스페이스 | ✅ | Admin OAuth, 워크스페이스 약관 |
| (옵션) Notion 페이지 | ✅ | 작성자 동의 (관리자 OAuth) |

→ **영업 멘트 핵심**: "환자 데이터는 절대 안 봅니다. 만지면 의료법·PIPA 위반이고, 저희 사업 망합니다. 저희가 보는 건 원장님 머릿속 + 직원 회의 + 종이 회의록 — 이게 다입니다."

## 3. 데모 흐름 세부 (Week 1 Day 1 미팅 30분)

### 분당 스크립트

```
0:00-0:03  인사 + 5/26 세션 후기 짧게
0:03-0:05  "오늘 30분 보여드리려는 거" (1줄: 원장님 머릿속 자산화)
0:05-0:08  Sediment 접속 + 보아치과 tenant 자동 생성 (라이브)
0:08-0:13  🎤 [라이브] 원장님께 음성 메모 5분 부탁
           - "요즘 환자 늘었네... 데스크 한 명 더 뽑을지 고민..."
           - "그래서 박위생사한테 이번주 안에 인사담당이랑 협의 시킬게..."
           - "아 그리고 이번달 회의는 6/3 월요일로 옮기자..."
0:13-0:16  (백그라운드에서 Whisper 처리 중, 다음 설명으로 시간 벌기)
           - "지금 처리 중이고요, 5분 음성 = 5분 안에 결과"
           - 그 사이에 PIPA 안 만지는 거 명시 (위 §2 표)
0:16-0:21  결과 화면 함께 보기:
           - Decision: "데스크 추가 채용 검토" (status: open)
           - Decision: "이번달 회의 → 6/3 월요일" (status: made)
           - Action: "박위생사 → 인사담당 협의 (이번주)"
           - 각 항목 클릭 시 음성 원본의 정확한 구간 재생 가능
0:21-0:26  RAG chat 시연:
           - 원장님: "내가 박위생사한테 뭐 시켰지?"
           - AI: "이번 주 안에 인사담당과 데스크 추가 채용 협의 [출처: 6/3 음성 메모, 09:15]"
0:26-0:28  Free tier 셋업 끝났음 안내 + 다음 일주일 미션:
           - "음성 메모 5-10개만 해보세요. 진료 끝나고 5분이면 충분"
           - 다음 미팅: 6/3 (Week 2 Day 8)
0:28-0:30  Q&A
```

### 가장 중요한 데모 모먼트

**0:16-0:21 — 결과 화면 함께 볼 때**

이 순간 원장 표정이 모든 걸 결정함. 핵심:
1. 음성 원본 ↔ 추출 결과 정확한 매핑 (출처 클릭 가능)
2. 결정의 status가 자동 분류됨 (made vs open)
3. 액션의 owner가 자동 인식됨 (박위생사)
4. 한글 어휘 자연스럽게 처리됨 (Whisper KO + Claude KO)

**0:21-0:26 — RAG chat 시연**

"이게 우리 회사 매뉴얼" 이라는 깨달음의 순간. 위생사에게 직접 보여줄 거 예고.

## 6. 가격 협상 카드

### 보아치과 적정가 분석

- 6-9명 (Studio tier 적합 — 10명 이하)
- 우리 cost-to-serve: ~$3-8/mo (LLM + storage)
- 시장 sweet spot (치과 archetype): ₩50K-100K/mo
- ICP rev2 권장: **₩99,000/mo or ₩990,000/yr (1달 무료)**

### 협상 카드 (높은 → 낮은 순)

1. **첫 카드**: ₩99,000/mo (정가)
2. **첫 양보**: ₩990,000/yr 연간 결제 (2개월 무료 효과)
3. **두 번째 양보**: 첫 3개월 ₩49,000 (₩300K 할인) — 케이스 스터디 권한 받는 조건
4. **마지노선**: ₩49,000/mo 평생 가격 (early adopter — 영원히) — 대신 동영상 인터뷰 / 컨퍼런스 발표 의무

### 케이스 스터디 권한이 가장 큰 가치

원장이 동의해주면:
- D archetype 영업 시 reference customer (1개 = 다음 5-10개 close 가능)
- HypeProof Lab 강의/컨설팅 자료
- 미디어 노출 (브런치, 인터뷰 etc.)
- 가격 할인보다 훨씬 큰 가치

## 7. 실패 시나리오 + 대응

| 실패 시나리오 | 대응 |
|---|---|
| 원장이 음성 메모 안 함 (Week 1 사용 0회) | Week 1 Day 4 카톡 체크인 — 어떤 막힘 있는지 듣고 1:1 코칭 |

| 위생사 데모에서 신입 RAG 답변 부정확 | Week 3에서 데이터 더 쌓이면 정확도 ↑ 설명. 또는 prompt fine-tune 옵션 |
| 가격 거부 (₩50K 이하만 가능) | Starter ₩49K 옵션 제시 (ICP rev2의 잠정 tier) + 케이스 스터디 조건부 |
| "원장 부재시 직원이 못 굴린다" 우려 | white-glove 6주 + 월 1회 체크인 계약 옵션 |
